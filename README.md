# Guía de Rendición · versión web (beta)

**Ábrela en el celular: https://georgeaguilera.github.io/guia-rendicion/**

Para responsables de proyectos de los Fondos de Cultura: eliges el PDF de tu postulación y la página te dice qué documentos juntar cada mes,
cuándo vence cada rendición en SISREC, qué verificadores necesita cada actividad y qué hacer en cada situación («¿Qué hago si…?»).

- **Tus datos quedan solo en tu teléfono.** La página funciona entera en el navegador: el PDF y lo que marcas no se envían a ningún lado.
  Si borras los datos del navegador se pierde lo marcado, así que descarga tu proyecto (.rendicion) de vez en cuando.
- **El mismo archivo que el programa para Windows.** Un proyecto guardado con «Guardar una copia…» en el programa se abre aquí, y al revés.
- **Reglas al día.** Las reglas de rendición se bajan de [guia-rendicion-reglas](https://github.com/georgeaguilera/guia-rendicion-reglas),
  el mismo repositorio que usa el programa para Windows (instalador en sus *Releases*).
- **Se puede instalar.** Desde el menú del navegador, «Agregar a la pantalla de inicio»; después abre también sin internet.

Es una versión de prueba: orienta, pero no reemplaza tu convenio, las bases de tu concurso ni a tu supervisor del Ministerio.

Este repositorio solo tiene la página ya compilada (Blazor WebAssembly), que se publica con GitHub Pages; el código fuente es privado.

Idea, diseño y desarrollo: George Aguilera. Proyecto personal, no es un sitio oficial del Ministerio de las Culturas, las Artes y el Patrimonio.
